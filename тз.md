1. Название проекта
   Система учета и анализа личных финансов
2. Описание проекта
   Веб-приложение для учета личных доходов и расходов пользователя с возможностью анализа финансовых данных по категориям, периодам и другим параметрам.
   Пользователь может:
   ● фиксировать доходы и расходы
   ● классифицировать операции
   ● получать аналитику и отчеты
3. Сущности системы
   Пользователь, счет, категория, транзакция (пополнение / списание из системы), трансфер (перевод между счетами), отчет (опционально, не знаю нужна ли для этого сущность целая, потому-что отчет можно просто динамически формировать)
4. Функциональные требования
   4.1 Пользователь
   ● Регистрация
   ● Авторизация (логин + пароль)
   ● Выход из системы
   Работа с финансами:
   ● Добавление дохода/расхода
   ● Редактирование и удаление операций
   ● Просмотр списка операций
   ● Фильтрация по:
   ○ дате
   ○ категории
   ○ типу
   Категории (стоит ли делать категории отдельно для каждого пользователя, или оставить одну? как стоит сделать в рамках учебного проекта?):
   ● Создание категорий
   ● Редактирование
   ● Удаление
   Аналитика:
   ● Сумма доходов/расходов за период
   ● Баланс
   ● Группировка по категориям
   ● Простые таблицы
   4.2 Администратор
   ● Управление пользователями
   ● Просмотр статистики по системе
5. Архитектура
   Приложение должно быть реализовано по слоистой архитектуре:
   ● Controller (представление)
   ● Service (бизнес-логика)
   ● Repository (доступ к данным)
6. Стек технологий
   ● Framework: Spring
   ● ORM: Hibernate (Spring Data JPA)
   ● БД: PostgreSQL
   ● UI:
   ○ Thymeleaf или
   ● Сборка: Maven
7. Безопасность
   ● Авторизация через Spring Security
   ● Хранение паролей в зашифрованном виде (BCrypt)
   ● Разграничение ролей (USER / ADMIN)
8. Логирование
   ● Использование SLF4J + Logback
   ● Логирование:
   ○ ошибок
   ○ действий пользователя
9. Интерфейс
   Основные элементы:
   ● Форма логина/регистрации
   ● Таблица транзакций
   ● Форма добавления операции
   ● Страница аналитики
   ● Навигационное меню
